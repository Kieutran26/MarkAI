Button

4 chiều của 1 nút bấm — variant, size, icon, state. Nhìn đơn giản nhưng quyết định toàn bộ interaction design.

01
Button Variants
4 loại variant — mỗi loại có mức nhấn mạnh khác nhau. Không phải "đẹp hơn" mà là "quan trọng hơn".
PRIMARY
Default
Primary = hành động chính. Secondary = phụ. Outline = nhẹ. Ghost = gần vô hình. Variant = weight của button.
02
Button Sizes
4 cấp size — cùng variant, khác diện tích. Size = visual hierarchy, không phải美感 preference.
LARGE
padding: 14px 28px
Size = hierarchy. CTA lớn, cancel nhỏ. Đừng chọn size vì "trông hợp" — chọn vì "nếu quan trọng thì to".
03
Button with Icons
Icon bên trái/trái = clarify action. Icon only = tiết kiệm space khi label thừa.
ICON LEFT
icon-left
Icon = shortcut cho não. Thấy "+" biết ngay là "tạo mới". Label có thể bỏ khi icon đã đủ rõ — icon-only button.
04
Button States
Default → Hover → Pressed → Disabled → Loading. 5 state, mỗi cái có rule riêng.
DEFAULT
Default
5 state = lifecycle. Disabled ≠ hidden — user thấy button nhưng biết không thể click. Loading = "đang xử lý, đợi".
