01

Máy cá nhân (Local)

Đang code...

Môi trường Local là chiếc máy tính cá nhân của lập trình viên. Đây là nơi duy nhất bạn có thể làm sai, làm thử thoải mái mà không ai biết.

02

Thử nghiệm (Staging)

Đang kiểm thử

Staging là một server "nháp" giống hệt server thật. Đội ngũ testers sẽ vào đây để kiểm tra lần cuối xem code có lỗi gì trước khi ra mắt khách hàng.

03

Sống thật (Production)

Live & Phục vụ user

Production là "mặt tiền" của ứng dụng. Đây là nơi khách hàng thật truy cập. Mọi thứ ở đây phải cực kỳ ổn định và đã được kiểm chứng kỹ càng.

04

Biến môi trường

# Tùy theo môi trường:
DB_URL = "localhost:3000"
API_KEY = "sk_test_..."
DEBUG = true

Mỗi môi trường dùng một bộ Config riêng. Ví dụ: Local dùng dữ liệu giả, Production dùng dữ liệu thật. Code sẽ tự động "nhận diện" để chạy đúng.
