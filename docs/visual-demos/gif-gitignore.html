03 / 04
5 rule phải có trong mọi project
.env
API key, database URL, mật khẩu
node_modules/
24,000+ file — cài lại từ package.json là có
.DS_Store
File ẩn hệ thống Mac, vô nghĩa trên server
*.log
Log lỗi runtime, không ai cần đọc trên repo
credentials.json
File chứa mật khẩu, token xác thực — tuyệt đối không up
→ Copy 5 dòng này vào .gitignore đầu tiên → tránh 90% rủi ro lộ secret.
04 / 04
2 ký tự quan trọng: * và !
*.env →
.env .env.local .env.production
node_modules/ →
toàn bộ thư mục
!.env.example →
.env.example
! = ngoại lệ → file này ĐƯỢC up
→ * = match tất cả, / = thư mục, ! = bỏ qua rule. Prompt AI viết .gitignore dùng 3 ký tự này.
