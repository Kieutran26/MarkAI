Hosting = thuê chỗ đặt code trên máy của người khác. Máy bạn tắt thì web tắt. Máy chủ (server) thì chạy 24/7. Khi dev nói "chưa deploy lên hosting" → code vẫn chỉ nằm trên máy dev, ai khác chưa xem được.

Khi hosting "chết"

03 / 04
T+0s
Website bình thường
User truy cập, server xử lý, trả về trang web
T+1s
Server sập đột ngột
RAM đầy, CPU quá tải, hoặc nhà cung cấp cắt điện
5xx SERVER ERROR
T+5s
User thấy lỗi, ads vẫn chạy
Tiền ads bị đốt vào trang lỗi — mất khách, mất tiền thật
T+2ph
Dev nhận thông báo, bắt đầu kiểm tra
Kiểm tra log → xác định nguyên nhân → restart server hoặc chuyển hosting
T+15ph
Khôi phục xong
Nhưng nếu chạy ads lúc sập → tiền đã mất không lấy lại được
Hosting chết = ads đốt vào vùng trống. Khi thấy lỗi 5xx, việc đầu tiên là tắt ads — không phải đợi dev fix xong. marketer biết đọc mã lỗi giúp phản ứng đúng tốc độ, thay vì gửi screenshot cho dev rồi chờ.

Hosting là bước cuối cùng trước khi user thấy sản phẩm. Code đúng 100% nhưng không deploy lên hosting → bằng không. Khi dev nói "đã push rồi", hỏi rõ "đã deploy lên hosting chưa" vì hai việc đó khác nhau.

Mục tiêu: Click từng bước theo đúng thứ tự flow deploy → thấy ngay trạng thái thay đổi trên "màn hình user". Nếu click sai thứ tự → không có gì xảy ra.
