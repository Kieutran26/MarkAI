01

Token hóa

Viết copy cho AI chat bot
24 ký tự → 6 tokens

LLM không đọc theo chữ — nó cắt text thành token. 1 token có thể là 1 chữ, nửa chữ, hoặc 1 khoảng trắng. Token ≠ ký tự ≠ chữ.

02

Dự đoán lần lượt

Slogan cho app fitness:
68% Đẩy
91% giới
85% hạn
79% của
72% bạn
94% !

LLM không "nghĩ rồi viết" — nó đoán token tiếp theo, lần lượt, dựa trên xác suất. Thanh nhỏ = nó cũng cân nhắc từ khác nhưng chọn từ này.

03

Cửa sổ ngữ cảnh

Context Window = bộ nhớ ngắn hạn của LLM. Khi quá nhiều token, các nội dung cũ ở đầu sẽ bị "đẩy" ra để nhường chỗ cho cái mới.

04

Nhiệt độ

Prompt: "Slogan cho app fitness:"
T=0.0
Đẩy giới hạn của bạn!
T=0.7
Vượt qua giới hạn, trở thành phiên bản tốt hơn của chính mình.
T=1.5
Cơ thể bạn là bản nháp đầu tiên — hãy xé nó lên và viết lại từ đầu.

Temperature = nấc sáng tạo. T thấp → nhất quán, lặp lại. T cao → bất ngờ, nhưng dễ đi lạc. Code cần T thấp, content cần T vừa.

LLM = Large Language Model, mô hình đoán token tiếp theo dựa trên hàng tỷ văn bản đã học. Ba thứ marketer cần nhớ: (1) nó tính theo token không phải chữ — prompt dài = tốn kém, (2) nó có giới hạn context window — quá dài là quên phần đầu, (3) temperature điều khiển mức sáng tạo — code cần thấp, content cần vừa. Khi vibecode, nói "dùng temperature 0.2, context window 8K" thay vì "cho nó thông minh lên" — dev hiểu ngay.
