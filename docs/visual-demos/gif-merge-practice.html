Trình mô phỏng Gộp (Merge)

Hãy tưởng tượng bạn có 2 bản thiết kế. Merge là cách bạn đưa bản mới vào bản gốc một cách an toàn. Hãy chọn tình huống bên dưới:

1. Bạn đang muốn làm gì?
🚀 Đưa Tính năng mới lên web Dùng khi bạn vừa thiết kế xong 1 module (ví dụ: Popup mới).
🔄 Lấy code mới từ đồng nghiệp Dùng để đảm bảo bạn không bị lạc hậu so với cả team.
🚑 Sửa lỗi khẩn cấp (Hotfix) Dùng khi web đang có lỗi cần fix và đẩy lên ngay.
2. Kiểu gộp mong muốn
📦 Nén gọn gàng (Squash) Khuyên dùng: Giúp lịch sử web sạch sẽ, dễ quản lý.
🛤️ Giữ nguyên chi tiết (Standard) Dùng khi bạn muốn lưu lại từng lần chỉnh sửa nhỏ.
3. Nếu có xung đột (Conflict)?
🔍 Dừng lại để tôi tự chọn An toàn nhất: Bạn sẽ quyết định lấy code của ai.
🙋‍♂️ Ưu tiên bản của tôi Dùng khi bạn chắc chắn code mình là bản mới nhất.
