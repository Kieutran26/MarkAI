Navbar

thanh điều hướng — thành phần cố định ở đầu mỗi trang

Navbar là thanh điều hướng nằm ở đầu (hoặc cạnh) mỗi trang — chứa logo, menu links, và nút hành động. Xuất hiện trên tất cả các trang, giữ nguyên khi user scroll (sticky), và thay đổi hình dạng trên mobile (hamburger menu). Lỗi navbar = user không biết đang ở đâu.

Nhấn vào một trạng thái để xem giải thích chi tiết.

02 — Thực hành

Mục tiêu: Bật/tắt từng state để xem navbar thay đổi realtime. Thử kết hợp nhiều state cùng lúc — ví dụ: scrolled + active + hide logo.

Đây là những gì user thực sự trải nghiệm khi dùng website.

Nội dung trang nằm bên dưới navbar. Khi scroll, navbar giữ nguyên vị trí (sticky).
Default: navbar nằm trên nền tối, logo + links + nút CTA hiển thị đầy đủ.

Thử kết hợp: Bật Scrolled + Active + Ẩn Logo để thấy navbar "đầy đủ state" — giống lúc user scroll đến section Pricing.

Tại sao marketer cần biết

Khi feedback "thêm menu item" — đó là thêm link vào navbar component, không phải chèn text bất kỳ đâu. Khi nói "navbar bị che nội dung" — dev cần biết để thêm z-index hoặc padding. Khi nói "ẩn logo trên mobile" — dev biết đó là 1 toggle trong navbar config. Biết các state của navbar = biết yêu cầu chính xác từng phần tử.
