PORT

infra

Số hiệu cửa trên máy tính — mỗi service mở một cửa, hai app không thể共用 cùng một cửa

01

Port là cửa số

Server
→ :80 HTTP
→ :443 HTTPS
→ :3000 Dev Server
→ :5432 PostgreSQL
192.168.1.5:80 192.168.1.5:443 192.168.1.5:3000 192.168.1.5:5432
IP addressPort

Port = số hiệu cửa trên máy. Request đến "192.168.1.5:3000" nghĩa là gõ cửa số 3000. Không có port → không biết gõ cửa nào.

02

Port quy ước

:80
HTTP
Web không mã hóa
:443
HTTPS
Web có SSL/TLS
:3000
Dev
React, Next.js, Express
:5432
PgSQL
Database PostgreSQL
:8080
Proxy
Nginx, Tomcat

Một số port là quy ước — 80 = web, 443 = web bảo mật. Dev thường dùng 3000/8080. Khi dev nói "chạy 3000" = app đang mở cửa 3000.

03

Xung đột port

Frontend
:3000 OK
Backend
:3000 FAIL
EADDRINUSE: address already in use :::3000

Hai app không thể mở cùng một port. App sau bị lỗi EADDRINUSE. Khi đọc log thấy lỗi này → có ai đang chiếm port đó rồi.

Localhost = máy bạn. Cùng một máy, khác port → gặp app khác. localhost:3000 là frontend, localhost:5432 là database — cùng máy nhưng hai thế giới.

Port = số hiệu cửa trên máy tính. Mỗi service (web, database, API) mở một cửa riêng theo quy ước (80=web, 5432=PostgreSQL). Hai app không thể dùng cùng một port → lỗi EADDRINUSE. Khi dev nói "chạy port 3000" nghĩa là app đang mở cửa 3000. Khi đọc log thấy "port already in use" → cửa bị chiếm, cần kill process cũ hoặc đổi port.
