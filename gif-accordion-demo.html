01

Single Open

SINGLE OPENFAQ PATTERN
state: item 0 open → switch → item 1 open

Mở 1 item thì item cũ tự đóng. Hợp với FAQ, pricing, nơi user nên tập trung vào từng câu một.

02

Multiple Open

MULTIPLE OPENSETTINGS
state: item 0 open → item 1 open → both stay open

Nhiều item có thể mở cùng lúc. Hợp với settings, filter, nơi user cần so sánh nhiều nhóm nội dung.

03

With Icons

WITH ICONSVISUAL HINTS
state: chevron → plus/minus → arrow

Icon không chỉ để trang trí. Nó là hint trạng thái báo cho user biết vùng này có thể mở rộng.

04

Nested

NESTEDIN CARD
state: outer opens → inner 0 opens → inner 1 opens

Accordion lồng nhau giúp chia nội dung theo tầng. Dùng khi thông tin phức tạp và có phân cấp.
