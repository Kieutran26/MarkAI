API key là "chìa khóa" truy cập dịch vụ. Ai có key, ai có quyền dùng — và bị tính phí.

API KEY = TIỀN THẬT
  • Không bao giờ commit API key vào Git — bot scan sẽ lấy key trong vài phút.
  • Không gửi API key qua Slack, email, Google Docs — bất kỳ ai đọc được đều có thể dùng.
  • Không để API key trong file public (HTML, JS client) — inspect element là thấy.
  • Luôn để API key trong .env hoặc environment variable — chỉ server mới đọc được.
