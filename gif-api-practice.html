Mục tiêu: Nhấn từng bước để xem một API request thực sự đi ra sao — từ lúc bạn gửi yêu cầu đến khi nhận được dữ liệu.

STEP 1
Prepare
App chuẩn bị yêu cầu
STEP 2
Authenticate
API key đi kèm header
STEP 3
Process
Server xử lý yêu cầu
STEP 4
Respond
Dữ liệu trả về app
Your App — Chuẩn bị request
// Bạn muốn lấy thông tin user từ API
const email = "lan@company.com";
const endpoint = "https://api.example.com/users";

// Chưa có gì đặc biệt — chỉ là dữ liệu đầu vào
Tiếp theo: API key sẽ được gắn vào header...
Request Header — API key đi kèm
GET /users?email=lan@company.com HTTP/1.1
Host: api.example.com
Authorization: Bearer sk-proj-aB3dE...fG7hI ← KEY Ở ĐÂY
Content-Type: application/json
Key đi trong mỗi request — nếu bị chặn/gián điệp, người khác có thể gọi API bằng tiền của bạn.
Tiếp theo: Server nhận và kiểm tra key...
Server — Xử lý yêu cầu
Server đang xử lý...
// Server làm 3 việc trong vài mili-giây:
1. Kiểm tra API key hợp lệ không
2. Kiểm tra permissions (có quyền read không?)
3. Tìm user trong database và lấy dữ liệu

// Nếu key sai hoặc hết tiền → 401/403
Tiếp theo: Dữ liệu trả về...
