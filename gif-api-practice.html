API REQUEST FLOW

Chạy mô phỏng để hiểu cách dữ liệu di chuyển từ App đến Server.

STEP 1Prepare
STEP 2Auth
STEP 3Process
STEP 4Respond
Your App — Chuẩn bị yêu cầu
// Bước 1: Khai báo endpoint và dữ liệu cần lấy
const endpoint = "https://api.example.com/users";
const query = "lan@company.com";

App chuẩn bị các thông tin cần thiết trước khi gửi đi.

Request Header — Gắn mã bảo mật
GET /users?email=lan@company.com
Authorization: Bearer sk-proj-aB3dE...
Content-Type: application/json

API Key được gắn vào Header để Server xác thực danh tính của bạn.

Server — Xử lý nghiệp vụ
// 1. Xác thực API Key
// 2. Kiểm tra quyền truy cập (Read)
// 3. Truy vấn Database lấy thông tin User

Server kiểm tra "chìa khóa" và tìm kiếm dữ liệu bạn yêu cầu.

Response — Kết quả trả về
{
  "name": "Lan Nguyen",
  "role": "Marketer",
  "plan": "Pro"
}
NameLan Nguyen
RoleMarketer
PlanPro
