Hình ảnh dùng trong project: logo, icon, ảnh background, ảnh thumbnail. Mỗi định dạng có mục đích khác — SVG cho icon (phóng to không mờ), WebP cho web (nhẹ hơn JPG 30-50%).

File font định dạng WOFF2/TTF — browser tải về để hiển thị text đúng kiểu. Thiếu file font → text fallback về font hệ thống (Arial, Times New Roman), phá vỡ toàn bộ visual design.
Font là asset nặng nhất sau video. Một font family đầy đủ (bold, regular, italic) có thể 200-500KB. Dev dùng WOFF2 thay vì TTF để giảm 60-70% dung lượng. Khi designer nói "dùng font X" nhưng không cung cấp file → dev không thể làm gì.
