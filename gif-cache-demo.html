01. Cache Miss (Lần đầu)

CHẬM
Bạn
Cache
Server
Hành trình: Bạn → Cache (Trống) → Server → Bạn MISS

Khi bạn yêu cầu dữ liệu lần đầu, Cache chưa có sẵn. Hệ thống phải đi quãng đường xa đến Server để lấy, sau đó mới lưu vào Cache cho lần sau.

02. Cache Hit (Lần sau)

CỰC NHANH
Bạn
Cache
Server
Hành trình: Bạn → Cache (Có sẵn) → Bạn HIT

Dữ liệu đã có sẵn ở "ngay cạnh" bạn (trong Cache). Không cần gọi đến Server xa xôi nữa, giúp ứng dụng phản hồi ngay lập tức.

03. Ví dụ thực tế

DỄ HIỂU
🏠
NHÀ BẾP
(User)
↓
🧂
KỆ BẾP
(Cache)
↓
🛒
SIÊU THỊ
(Server)

Kệ bếp giống như Cache. Bạn để sẵn gia vị ở đó để lấy cho nhanh. Khi nào dùng hết trên kệ, bạn mới phải tốn công đi siêu thị để mua thêm.

04. Tại sao cần Cache?

LỢI ÍCH
Tốc độ tải trang + 500%
Tiết kiệm 4G/Wifi Tối đa
Gánh nặng Server Giảm 80%

Cache không chỉ làm web nhanh hơn mà còn giúp điện thoại của bạn đỡ tốn pin và tốn dung lượng mạng vì không phải tải đi tải lại một thứ.
