Gõ text → Enter → kết quả ngay
CLI = Command Line Interface — điều khiển máy tính bằng văn bản. Thay vì click chuột qua menu, dev gõ lệnh như ls cd npm run. Nhanh hơn GUI nhiều lần khi biết mình muốn gì. Khi dev gửi bạn screenshot terminal → đó là CLI.

Các lệnh phổ biến

02 / 04
pwd
$ pwd
"Tôi đang ở đâu?" — hiện đường dẫn thư mục hiện tại
ls
$ ls
"Có gì ở đây?" — liệt kê file và thư mục
cd
$ cd src/components
"Di chuyển đến..." — chuyển thư mục làm việc
mkdir
$ mkdir assets
"Tạo thư mục mới" — tạo folder
npm run
$ npm run dev
"Khởi động project" — chạy script đã cấu hình
git
$ git commit -m "fix..."
"Lưu phiên bản code" — quản lý thay đổi
6 lệnh này xuất hiện trong 90% cuộc hội thoại với dev. Không cần nhớ cú pháp chính xác — cần biết ls là "xem file", cd là "di chuyển", npm run là "chạy project". Đủ để hiểu dev đang làm gì khi họ chia sẻ terminal.

Thực hành

Mục tiêu: Gõ lệnh vào terminal → thấy kết quả trả về ngay. Thử lệnh sai để thấy cách CLI báo lỗi.
zsh — ~/project
// Gõ lệnh hoặc click nút nhanh bên trên
Thử click nút "xyz" — lệnh không tồn tại, CLI sẽ báo lỗi. Đó chính xác là lúc dev thấy "command not found" và marketer hay hoảng không biết chuyện gì.
