Commit không phải là copy file. Nó là một tấm ảnh "chụp nhanh" trạng thái code của bạn. Bạn có thể quay lại bất kỳ tấm ảnh nào trong quá khứ nếu code hiện tại bị lỗi.

Thực hiện Commit

ACTION
bash — ~/vibecode
Luôn có 2 bước: git add (chọn file) và git commit (đóng gói kèm ghi chú).
