01

Conflict là sao

BẠN color: #fff;
TEAM color: #000;
CONFLICT
Hai edit cùng dòng → Git không biết giữ cái nào

Conflict xảy ra khi hai người sửa cùng một dòng trong cùng file. Git không thể tự gộp — phải có người quyết định giữ cái nào.

02

Nhận diện trong file

index.html CONFLICT
1.hero {
2<<<<<<< HEAD
3 color: #fff;của bạn
4=======
5 color: #000;của team
6>>>>>>>> main
7}
MERGE CONFLICT — cần xử lý tay

Khi conflict, Git chèn marker vào file: <<< bắt đầu phần bạn, ======= phân cách, >>>> bắt đầu phần team. Nhìn thấy mấy dấu này = đang có conflict.

03

Ba nguyên nhân phổ biến

1
Cùng sửa 1 dòng
Bạn và team đều thay .hero color — Git không tự gộp được
2
Không pull trước khi push
Code trên GitHub đã mới hơn bản local — đẩy lên bị clash
3
Branch tách nhau quá lâu
Feature branch không merge lâu → main đã thay nhiều chỗ

Ba nguyên nhân: cùng dòng (phổ biến nhất), thiếu pull (quên sync), branch cũ (chờ quá lâu). Nguyên nhân nào cũng dẫn đến cùng kết quả: phải resolve tay.

04

Luồng xử lý

Detect
Read
Decide
Commit
Git báo "CONFLICT in file"
Mở file, đọc marker, hiểu ai sửa gì
Chọn giữ của bạn, team, hoặc gộp
Xóa marker, commit lại — xong

Bốn bước fix: Phát hiện (Git báo lỗi) → Đọc (mở file, xem marker) → Quyết định (chọn version) → Commit (lưu kết quả). Không qua bước nào cũng được.
