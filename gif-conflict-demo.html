01

Giải mã Marker

<<<<<<< HEAD (Của bạn)
background: #ff0000;
======= (Vách ngăn)
background: #00ff00;
>>>>>>> feature-nav (Của team)
Anatomy

Git sử dụng các dấu Marker để đánh dấu vùng bị đụng độ. Bạn cần xóa chúng sau khi đã chọn được nội dung ưng ý.

02

Các lựa chọn

Keep Current
Keep Incoming
Keep Both
Resolution Mode

Bạn có thể chọn giữ lại code của mình (Current), code của đồng nghiệp (Incoming) hoặc gộp cả hai lại nếu cần thiết.

03

Nguyên nhân

CONFLICT!
Logic: Same Line Edit

Đụng độ xảy ra khi hai người cùng sửa cùng một dòng hoặc một người xóa file trong khi người khác đang sửa.
