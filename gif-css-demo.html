CSS Hoạt động thế nào?

h1
  Hello
h1 {
  color: #e88;
}

Hello

CSS = lớp "áo" cho HTML. Browser đọc file cấu trúc (HTML) và file thẩm mỹ (CSS) để render ra trang web hoàn chỉnh.
Cú pháp

Selector & Declaration

h1 {
  color: #e88c2e;
  font-size: 48px;
}
Selector: Chọn thẻ h1
Chọn gì -> Đổi gì -> Thành bao nhiêu. Hiểu 3 phần này giúp bạn prompt AI chính xác hơn: "Đổi màu (property) của nút (selector) thành cam (value)".
