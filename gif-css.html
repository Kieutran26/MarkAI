Mô tả

CSS = lớp "áo" cho HTML. HTML là xương (cấu trúc), CSS là da thịt (màu sắc, kích thước, vị trí). Browser đọc cả hai file → render ra trang web bạn thấy. Khi nói "sai CSS" → nghĩa là trang đúng nội dung nhưng sai hình dạng.

Selector + Declaration

02 / 04
h1 {
color: #d4622b;
font-size: 48px;
}
/* = selector { declaration } */
Selector
h1 — "tìm thẻ h1 trên trang". Có thể là tag, class (.btn), hoặc ID (#header).
Property
color — "đổi gì". Có hàng trăm: background, margin, padding, font-size...
Value
#d4622b — "đổi thành bao nhiêu". Mỗi property chấp nhận kiểu value khác nhau.
Có 3 phần trong mỗi dòng CSS: chọn gì → đổi thuộc tính nào → giá trị bao nhiêu. Khi prompt AI "đổi màu nút", AI tạo ra selector (tìm nút) + declaration (color: giá trị). marketer hiểu 3 phần này → prompt chính xác hơn "đổi cái đó thành màu kia".

Mọi element trên web đều là một hình chữ nhật gồm 4 lớp lồng nhau. Content là nội dung thật. Padding = khoảng cách từ content đến border. Margin = khoảng cách từ border đến element bên cạnh. Tổng kích thước = 4 lớp cộng lại — marketer nói "nút to quá" thường là margin hoặc padding bị dư.

Responsive Design

04 / 04

Tablet
Mobile
/* CSS tự động đổi layout theo kích thước màn hình */
@media (max-width: 768px) {
.grid { grid-template-columns: 1fr 1fr; }
}
@media (max-width: 480px) { .grid { grid-template-columns: 1fr; } }
Responsive = cùng HTML, CSS tự điều chỉnh layout theo màn hình. 3 cột trên desktop → 2 cột trên tablet → 1 cột trên mobile. Không phải tạo 3 trang riêng. Khi marketer báo "mobile bị vỡ" → dev cần sửa CSS media query, không phải viết lại trang.

Thực hành

Mục tiêu: Kéo 4 slider để thay đổi margin, border, padding, content → thấy ngay cách box model ảnh hưởng đến kích thước thật của element.
Content
.box {
  margin: 16px;
  border: 3px solid;
  padding: 14px;
  width: 100px;
}
/* Tổng kích thước: 166px */
Để content=100px, kéo margin lên 40px → thấy element "to" ra rất nhiều dù nội dung không đổi. Đó là lý do marketer nói "nút to quá" nhưng dev nói "nút vẫn 100px" — vì họ đang nói về content, bạn đang thấy total size.
