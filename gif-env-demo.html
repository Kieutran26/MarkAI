01. Cấu trúc & Cách dùng

.env file
# Cấu hình Database
DB_HOST=localhost
DB_PASS=secret_123
# API Keys
STRIPE_KEY=sk_live_...
Mỗi dòng là một cặp KEY=VALUE. Dùng để lưu thông tin nhạy cảm tách biệt khỏi mã nguồn (code).
.env = kho lưu bí mật. Giống như tủ an toàn, code chỉ "mượn" chìa khóa khi cần chạy, không dán mật khẩu trực tiếp lên màn hình.

02. Quy tắc đặt tên

Naming
dbHost → DB_HOST
api key → API_KEY
stripe-key → STRIPE_KEY
Bắt buộc: VIẾT_HOA + GẠCH_DƯỚI. Không dùng dấu gạch ngang (dash) hay khoảng trắng. Sai quy tắc sẽ khiến code không thể nhận diện được biến.

03. Đa môi trường

Multi-env
.env.local
DB=localhost
DEBUG=true
.env.prod
DB=db.markai.vn
DEBUG=false
Cùng code, khác giá trị. File .env giúp ứng dụng tự động thay đổi cấu hình phù hợp với nơi nó đang chạy (máy cá nhân hay server thật).

04. Bảo mật & Git

Security
Dữ liệu bị rò rỉ!
PASSWORD=
Lộ mật khẩu trên GitHub...
Đừng bao giờ push .env! Hãy thêm .env vào file .gitignore. Lộ file này đồng nghĩa với việc dán mật khẩu lên bảng tin công cộng.
