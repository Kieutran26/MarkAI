Mục tiêu: Điền giá trị cho các biến .env → thấy ngay output thay đổi. Thử nhập sai tên biến để thấy lỗi.
.env config editor
DB_HOST=
DB_USER=
STRIPE_KEY=
DEBUG=
true
Presets
node server.js
Click "Wrong Name" → hệ thống tự đổi "DB_HOST" thành "db_host" (chữ thường). Terminal sẽ báo lỗi ngay. Đó chính xác là lỗi marketer hay mắc khi sửa .env.
