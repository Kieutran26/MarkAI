Git = cỗ máy thời gian cho code. Thay vì đặt tên file kiểu v1, v2, Git tự động chụp ảnh "checkpoint" kèm ghi chú. Bạn có thể quay lại bất kỳ thời điểm nào trong lịch sử chỉ bằng một lệnh.

Local & Remote

COLLABORATION
🖥
Local (Máy của bạn)
Nơi bạn gõ code và lưu commit. Chỉ mình bạn thấy.
↑ push / ↓ pull
☁
Remote (GitHub/GitLab)
Bản sao trên server để team chia sẻ và deploy lên web.
Code trên máy bạn (Local) là chưa đủ. Chỉ khi bạn push lên GitHub (Remote), AI mới có thể nhận diện thay đổi để hỗ trợ deploy hoặc review tiếp.

Lệnh Git Marketer cần biết

COMMANDS
git clone
Tải project từ GitHub về máy lần đầu tiên.
git pull
Tải bản cập nhật mới nhất từ team về máy bạn.
git branch
Kiểm tra xem bạn đang ở "nhánh" nào của dự án.
git checkout
Chuyển sang một phiên bản code hoặc tính năng khác.
Trong Vibe Coding, bạn thường chỉ cần clone và pull. Các lệnh thay đổi code phức tạp như commit hay push sẽ do AI Agent xử lý tự động cho bạn.
