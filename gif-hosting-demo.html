Rủi ro: Khi Hosting sập

09:00 - Web Live
10:15 - Server Down (Error 502)
10:20 - Ads vẫn chạy -> Mất tiền
Hosting chết = Đốt tiền Ads: Khi thấy lỗi 5xx, việc đầu tiên là tắt ads. Đừng đợi dev fix xong mới hành động.
