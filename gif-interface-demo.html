⚙ Hệ thống
Interface = điểm tiếp xúc giữa người dùng và hệ thống. Nó không phải "giao diện đẹp" — nó là cách bạn tương tác với một sản phẩm: click, gõ, nói, chạm, nhìn.
marketer nghĩ "interface" = thiết kế. Dev nghĩ "interface" = contract. Khi dev nói "xây interface" → họ đang tạo cách để frontend giao tiếp với backend (API). Khi designer nói "interface" → họ đang thiết kế cách user giao tiếp với app. Cùng từ, hai nghĩa.

Các loại Interface

02 / 04
GUI — Graphical
Giao diện đồ họa: nút, form, menu. Click và nhìn để thao tác.
Website, app mobile, dashboard
$ git commit
-m "fix"
CLI — Command Line
Gõ lệnh text trong terminal. Nhanh nhưng cần nhớ cú pháp.
Terminal, Git bash, npm
Touch Interface
Vuốt, pinch, chạm trực tiếp trên màn hình. Intuitive nhưng giới hạn thao tác phức tạp.
Mobile app, tablet, POS
Voice Interface
Nói để điều khiển. Không cần tay, nhưng hạn chế ngữ cảnh phức tạp.
Siri, Alexa, Google Assistant
Marketer chủ yếu làm việc với GUI. Nhưng khi dev nói "API interface" → họ đang nói về CLI-type interface giữa các hệ thống. Biết 4 loại này → hiểu dev đang nói interface nào mà không hỏi lại.

Interface trong thực tế

03 / 04
Mỗi element bạn thấy = 1 interface element.

Avatar — interface nhận diện người dùng
Card — interface hiển thị thông tin sản phẩm
Button — interface kích hoạt hành động
Input — interface nhập dữ liệu
Border highlight cam pulse → chỉ vào vùng "interface" giữa user và data.
Interface không chỉ là "nhìn đẹp" — là mỗi điểm user tương tác. Button, form, avatar, card — tất cả đều là interface.

Nguyên tắc Interface tốt

04 / 04
👁
Clarity — Rõ ràng
User nhìn vào biết ngay phải làm gì. Không cần đoán, không cần tìm.
Nút "Đăng ký" rõ ràng > nút "Tiếp" mơ hồ
PHÂN TÍCH
🔗
Consistency — Nhất quán
Cùng một kiểu tương tác xuất hiện ở mọi nơi. Không nút trái phải khác nhau.
Nút primary luôn cam ở mọi trang > trang này xanh trang kia đỏ
KIỂM TRA
⚡
Efficiency — Hiệu quả
Ít bước nhất để hoàn thành việc. Không bắt đi vòng.
Checkout 1 bước > checkout 5 trang riêng biệt
ĐO LƯỜNG
♿
Accessibility — Tiếp cận
Người khiếm khuyết vẫn dùng được. Không chỉ phục vụ người "bình thường".
Có alt text cho ảnh > ảnh vỡ không biết là gì
