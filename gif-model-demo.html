01

Model là gì

Viết caption cho serum mới
MODEL
Khám phá vẻ đẹp từ bên trong...
PROMPT → → RESPONSE

Model = hộp đen đã huấn luyện. Bạn đưa prompt vào, nó đẩy response ra. Bên trong nó "nghĩ" thế nào thì không cần biết — quan trọng là chọn đúng hộp.

02

Các phiên bản

4K ctx · Nhanh · $0.5/1M tok
BASELINE
GPT-4
8K ctx · Chậm 3x · $30/1M tok
CHÍNH XÁC

128K ctx · Nhanh · $5/1M tok
BEST

Cùng nhà làm, nhưng mỗi phiên bản khác nhau về context, tốc độ, giá, độ chính xác. GPT-4o không phải "GPT-4 bản mới" — nó là model khác, tradeoff khác.

03

Chọn model theo việc

Viết caption
GPT-3.5 — rẻ, đủ dùng
Debug code
GPT-4 — hiểu code sâu
Phân tích data
Claude — suy luận logic

Không có model "tốt nhất" cho mọi việc. Công việc khác → model khác. Viết caption bằng GPT-4 tốn tiền gấp 60 lần mà chất lượng chẳng khác bao nhiêu.

04

Model ≠ Chat App

model: gpt-4 = model: gpt-4
Chat UI
Viết caption serum
Khám phá vẻ đẹp...
Mỗi giọt serum...
API Call
{ "model": "gpt-4", "messages": [...], "temperature": 0.7 } → { "content": "Khám phá..." }
User gõ trực tiếp Code gửi request, nhận JSON

ChatGPT app và API cùng dùng cùng model, nhưng khác interface. Khi dev nói "tích hợp model qua API", họ không mở ChatGPT — họ gọi bằng code.
