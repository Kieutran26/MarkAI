Prompt Numeric pagination, showing page 1 of 10, 5 items per page

Pagination = cách chia dữ liệu lớn thành nhiều trang. Nhưng "thêm pagination" chưa đủ — cần nói rõ: numeric (chọn trang trực tiếp), prev/next (chỉ lùi/tới), hay load more (không có trang, nối thêm). Khi báo lỗi "không thấy data cũ", dev cần biết bạn đang ở trang mấy. Sai type → UX sai hoàn toàn dù data đúng.
