Responsive

thích ứng — cùng nội dung, layout tự đổi theo kích thước màn hình

Responsive là khả năng một trang web tự thay đổi layout khi kích thước màn hình đổi — desktop: nhiều cột, tablet: ít cột hơn, mobile: một cột. Cùng một code, cùng một content, khác cách trình bày. Dev dùng breakpoint để quyết định "ở kích thước nào thì đổi layout".

Nhấn vào một thiết bị để xem layout và breakpoint.

02 — Thực hành

Mục tiêu: Bấm chuyển giữa Desktop / Tablet / Mobile để thấy cùng một trang đổi layout realtime. Quan sát breakpoint và cấu trúc grid thay đổi.

Đây chính xác là những gì user trải nghiệm khi resize browser hoặc mở site trên điện thoại.

Tại sao marketer cần biết

Khi feedback "mobile trông bị lệch" — dev cần biết chính xác breakpoint nào bị lỗi (768px hay 1280px). Khi nói "thêm breakpoint cho tablet" — dev hiểu cần viết thêm media query. Khi thiết kế trên desktop mà không check mobile → đó là thiếu responsive, lỗi phổ biến nhất mà marketer có thể phát hiện trước user báo. Biết breakpoint = biết mô tả vấn đề chính xác.
