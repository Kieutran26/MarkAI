Border Radius

02 / 04
0px
Góc vuông — sharp, kỹ thuật, brutalist
4px
Vuông nhẹ — tool UI, dashboard, data-heavy
8px
Bo vừa — SaaS phổ biến, "an toàn"
16px
Bo mềm — consumer app, thân thiện
50%
Tròn hoàn toàn — avatar, icon, badge
Border-radius quyết định "vibe" của toàn bộ sản phẩm. Cùng một nút, đổi từ 0px → 16px là đổi từ "công cụ kỹ thuật" sang "app sinh viên". Prompt AI mà thiếu giá trị này → ra phong cách loạn.

Cùng shape, khác variant = khác mức độ chú ý. Filled = "nhấn vào đây". Outline = "tùy chọn". Ghost = "thông tin phụ". Khi prompt, nói rõ variant thay vì chỉ nói "nút màu cam".

Shapes in UI Components

04 / 04
Button
Shape chữ nhật + border-radius quyết định style nút. Pill = bo tròn hai đầu. Ghost = bỏ fill, chỉ giữ viền hoặc không.
xem border-radius đang tự động thay đổi
Card
Rectangle lớn chứa nội dung. Radius 0–4px → dashboard. 12–16px → landing page. 24px+ → mobile consumer app. Sai radius = sai hoàn toàn vibe sản phẩm.
M
đang morph vuông → tròn
Avatar
Square với radius thay đổi: 0px (GitHub style), 6px (Slack), 50% (Facebook, Instagram). Cùng ảnh, khác shape = khác brand identity.

Badge / Tag
Nhỏ, gắn vào nội dung khác. Bo góc thấp = tag kỹ thuật. Pill = status label. Dashed border = draft/chưa xác nhận.
email...
Input Field
Rectangle chứa text người dùng nhập. Radius gần như luôn match với button đi kèm. Nếu nút bo 16px mà input bo 0px → mất tính nhất quán ngay.
Shape không tồn tại độc lập — nó sống trong component. Khi báo dev "sửa nút này", nói rõ: rectangle, radius bao nhiêu, filled hay outline. Đó mới là spec đủ để dev không hỏi lại.
