01
Success Snackbar
Xác nhận action hoàn thành — kèm UNDO để quay lại nếu lỡ tay.
IDLE
Success
Profile updated successfully.
Undo
Snackbar = "làm xong rồi báo nhẹ" — không block, không cần đóng thủ công.
02
Error Snackbar
Báo lỗi không critical — kèm RETRY để user thử lại ngay.
IDLE
Error
Failed to delete item.
Retry
Error snackbar ≠ error modal. Lỗi nhẹ thì snackbar, lỗi nặng bắt buộc xử lý thì modal.
03
Info Snackbar
Cho user biết thông tin mới — kèm action để tìm hiểu thêm nếu quan tâm.
IDLE
Info
New version available.
Learn more
Info = "có chuyện này, biết cũng được". User có thể ignore — đó là điểm khác với modal.
04
Warning + Lifecycle
Cảnh báo không chặn — và timeline: appear → visible → auto-dismiss.
IDLE
Warning
Connection unstable.
Dismiss
Appear
Visible
Dismiss
Snackbar có vòng đời: slide up → hiện progress → tự slide down. Không cần user đóng.
