## 📁 Cấu Trúc Đặt Tên File

1. `gif-[thuật ngữ]-demo.html`: Bản demo trực quan giải thích khái niệm (ví dụ: `gif-spacing-demo.html`, `gif-api-demo.html`, `gif-button-demo.html`...).
2. `gif-[thuật ngữ]-practice.html`: Giao diện thực hành tương tác (ví dụ: `gif-spacing-practice.html`, `gif-border-practice.html`...).
3. `gif-[thuật ngữ].html` hoặc `gif-[thuật ngữ]2.html`: Các phiên bản visual gốc hoặc biến thể trực quan tương tác.
