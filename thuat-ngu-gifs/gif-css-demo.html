01

Chọn đối tượng

<h1>Tiêu đề chính</h1>
<button class="btn">Nút bấm</button>
<p>Đoạn văn bản</p>
Selector: h1

Dùng Selector để "trỏ" đúng phần tử cần trang trí (VD: tên thẻ, class hay ID) giữa hàng nghìn dòng code.

02

Trang trí thuộc tính

color: #E88C2E;
Vibecode
Declaration

Định nghĩa Property (thuộc tính) và Value (giá trị) để thay đổi màu sắc, font chữ hay kích thước của phần tử.

03

Cấu trúc hình hộp

Content
Padding
Box Model

Mọi thứ trên web đều là hình hộp. Bạn kiểm soát khoảng cách bằng Margin (ngoài), Padding (trong) và Border.
