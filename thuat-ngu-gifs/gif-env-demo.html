01

Cấu trúc

# Database config
DB_HOST=localhost
DB_USER=admin
# API Keys
STRIPE_KEY=sk_live_...

Mỗi dòng là một cặp KEY=VALUE. Nó giống như một cuốn sổ tay lưu trữ các thông tin "bí mật" mà code cần sử dụng.

02

Quy tắc

db name DB_NAME
apiKey API_KEY
port-num PORT

Luôn sử dụng VIẾT_HOA và dấu gạch dưới. Không dùng khoảng trắng hay dấu gạch ngang.

03

Môi trường

.env.local
API_URL=localhost:3000
.env.production
API_URL=api.markai.vn

Cùng một biến nhưng có giá trị khác nhau tùy vào việc ứng dụng đang chạy ở máy cá nhân hay server thật.

04

Bảo mật

.gitignore += ".env"

Đừng bao giờ đẩy file này lên GitHub! Hãy thêm .env vào .gitignore để giữ bí mật tuyệt đối.
