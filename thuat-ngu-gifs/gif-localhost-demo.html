01

Bản chất Local Host

localhost:3000
127.0.0.1

Local Host là máy tính cá nhân của bạn đóng vai trò như một máy chủ ảo. Nó có địa chỉ IP nội bộ mặc định là 127.0.0.1.

02

Phạm vi truy cập

localhost
VS
mywebsite.com

Localhost hoàn toàn riêng tư, chỉ bạn xem được. Để người khác xem, phải đưa code lên Hosting/Server (máy chủ công khai).

03

Vị trí trong luồng

1. Viết Code
2. Test (Localhost)
3. Deploy (Hosting)

Localhost nằm ở bước chạy thử nghiệm. AI báo "trên local nó chạy" nghĩa là code đã ổn, nhưng chưa đẩy lên cho user thật dùng.

04

Môi trường cách ly

💻
Localhost
🔥
🌍
Production

Localhost là "sân tập". Dù bạn làm hỏng dự án trên máy mình, website thật (Production) ngoài kia vẫn an toàn tuyệt đối.
