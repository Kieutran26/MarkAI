Local host = địa chỉ IP của chính máy bạn (127.0.0.1). Khi dev nói "xem trên local" → mở trình duyệt, nhập localhost:3000 → thấy project chạy trên máy dev. Không ai khác trên internet thấy được.

Local vs Hosting

02 / 04
LOCAL HOST
http://localhost:3000
Địa chỉ: 127.0.0.1
Truy cập: chỉ bạn
Mục đích: dev, test
Chi phí: không chia sẻ được
$ npm run dev
→ Server chạy tại localhost:3000
→ Mở trình duyệt → gõ localhost:3000
HOSTING (REMOTE)
https://mywebsite.com
Địa chỉ: tên miền công khai
Truy cập: mọi người
Mục đích: production
Chi phí: trả tiền hàng tháng
URL: chia sẻ được
$ git push → deploy → build
→ Server chạy tại mywebsite.com
→ Ai gõ URL → thấy trang web
Local = nơi test nhanh, miễn phí, riêng tư. Hosting = nơi chạy thật, có chi phí, công khai. Khi dev bảo "trên local nó hoạt động" → đúng, nhưng chưa ai khác thấy. "Đã deploy lên hosting" → lúc đó mới có người ngoài thấy được.

Local host nằm ở bước 2 trong flow dev.

1. Viết code trên máy →
2. Chạy trên local host để test →
3. Commit → push →
4. Deploy lên hosting →
5. Mọi người truy cập được
Local host là "bản nháp" trước khi đưa lên sân khán giả. Chạy trên local → sai cũng không ảnh hưởng ai. Deploy lên hosting → mới là "lên sân". marketer cần biết: "trên local OK" ≠ "trên production OK". Hai việc hoàn toàn khác nhau.

Tại sao marketer cần biết

04 / 04
1
Dev bảo "lỗi local thôi, không phải lỗi thật"
Hiểu local ≠ production → không hoảng khi dev nói "trên local nó chạy". Nhìn vào localhost thấy lỗi là bình thường, không phải "web bị hỏng".
2
"Lên production đã deploy chưa?"
Local chỉ là bước test. Deploy lên hosting mới là đưa code lên server thật. localhost:3000 không phải mywebsite.com.
3
"Cho tôi link xem trên local"
Không thể — local chỉ truy cập được trên máy dev. marketer không cần link local. Muốn xem → cần deploy lên staging/hosting.
Biết phân biệt local vs production để phản ứng đúng. Local lỗi → "OK, fix xong rồi, chưa deploy". Production lỗi → "người dùng đang bị ảnh hưởng, cần ưu tiên". Hai tình huống, hai mức độ ưu tiên hoàn toàn khác nhau.
