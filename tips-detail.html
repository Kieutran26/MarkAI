CLAUDE.md — cách để AI nhớ toàn bộ context dự án của bạn

✳ 27·04·2026 · Vibecode · Cursor · Claude Code
✳ Thông tin tip
Số tip #60
Danh mục Vibecode
Tools liên quan Cursor · Claude Code
Độ khó Cơ bản
Thời gian áp dụng ~5 phút
✳ Chia sẻ tip này

Một trong những vấn đề lớn nhất khi vibecode là mỗi lần mở chat mới với AI, bạn lại phải giải thích lại toàn bộ: đây là project gì, dùng tech stack nào, convention của mình ra sao, ai là end user... Mất thời gian, dễ bỏ sót, và AI thường code không đúng ý ngay từ đầu.

Giải pháp: tạo file CLAUDE.md ở root của project. Đây là file "bộ nhớ" mà Claude (và Cursor AI) sẽ tự động đọc mỗi khi bạn bắt đầu session mới.

✳ Key insight: CLAUDE.md không phải instruction — nó là context. Viết như đang giới thiệu project với một dev mới vào team, không phải ra lệnh cho AI.

CLAUDE.md nên chứa những gì?

Không có template cứng nhắc, nhưng một CLAUDE.md hiệu quả thường có 5 phần sau:

01
Project overview
Project này là gì, dùng để làm gì, target user là ai. 3–5 câu ngắn là đủ.
02
Tech stack
Framework, database, deploy platform, language, styling. Ví dụ: Next.js 15 · Supabase · Vercel · TypeScript · Tailwind v4.
03
Code conventions
Naming convention, folder structure, component style. Nếu có design system — tóm tắt màu sắc, font, rules quan trọng nhất.
04
Những gì KHÔNG làm
Đây là phần quan trọng nhất. Ví dụ: "Không dùng border-radius", "Không thêm package mới khi chưa hỏi", "Không xóa comment".
05
Current status / context
Đang build trang nào, đang fix bug gì, phase hiện tại là gì. Update thường xuyên khi project thay đổi hướng.

Ví dụ thực tế — CLAUDE.md của markAI.vn

CLAUDE.md 
# markAI.vn — Project Context

## Project
Nền tảng học AI ứng dụng cho dân Marketing Việt Nam.
Miễn phí 100%. Triết lý: học xong dùng được ngay.

## Tech Stack
- Framework: Next.js 15
- Database: Supabase
- Deploy: Vercel
- Language: TypeScript
- Styling: Tailwind v4

## Design Rules (QUAN TRỌNG)
- KHÔNG border-radius (trừ 3 dots terminal)
- KHÔNG box-shadow bất kỳ đâu
- Font: Instrument Serif (heading) · DM Mono (UI) · DM Sans (body)
- Accent: #E8410A — chỉ dùng cho hover/badge/em/active

## Current Focus
Đang build trang /tips và /tips/[slug].
✳ Lưu ý: Giữ CLAUDE.md dưới 200 dòng. Quá dài thì AI sẽ "quên" phần cuối. Chỉ ghi những gì quan trọng và thường bị AI làm sai.

CLAUDE.md vs Cursor Rules — dùng cái nào?

Tiêu chí CLAUDE.md Cursor Rules (.cursorrules)
Mục đích Context về project Rules về cách AI respond
Nội dung Tech stack, goals, current status Tone, format, coding style cụ thể
Dùng khi Giới thiệu project với AI Muốn AI luôn code theo style nhất định
Tool hỗ trợ Claude Code, Cursor Cursor (chỉ)
Kết luận Dùng cả hai — không xung đột Dùng cả hai — không xung đột
"Mình tốn 30 phút viết CLAUDE.md một lần — nhưng tiết kiệm ít nhất 5 phút mỗi session không cần giải thích lại. Sau 1 tháng là lời rõ."
✳ markAI · kinh nghiệm thực tế khi build dự án này

Áp dụng ngay — 3 bước trong 5 phút

Không cần đợi project hoàn chỉnh. Tạo CLAUDE.md ngay hôm nay với nội dung tối thiểu rồi bổ sung dần:

01
Tạo file CLAUDE.md ở root project
Ngang hàng với package.json và .gitignore — không đặt trong subfolder.
02
Viết 5 mục cơ bản
Project là gì · Tech stack · Convention quan trọng nhất · Những gì KHÔNG làm · Đang focus vào gì. Dùng Markdown, viết tiếng Việt được.
03
Commit vào Git
CLAUDE.md nên được version control — khi project thay đổi hướng thì update file này trước khi bắt đầu session mới.
