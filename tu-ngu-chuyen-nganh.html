API
Application Programming Interface
Hạ tầngCode
Cầu nối giúp các phần mềm nói chuyện với nhau. Khi bạn gửi form trên web và data tự xuất hiện trong Google Sheet — đó là API làm việc. Bạn không thấy nó, nhưng nó ở khắp nơi.
Ví dụ thực tế
✳ "Mình muốn khi khách điền form trên landing page, data tự vào Airtable. Cần xài API của Airtable."

Array
Mảng / Danh sách
Code
Danh sách các item được xếp theo thứ tự. Giống như một cột Excel — mỗi ô là một item. Array trong code thường trông như này: ["Hà Nội", "TP.HCM", "Đà Nẵng"].
Ví dụ thực tế
✳ AI trả về "danh sách categories" — đó thường là một array mà code của bạn sẽ loop qua để hiển thị từng cái.

Design

Ví dụ thực tế
✳ "Folder /assets/images/ chứa toàn bộ ảnh của campaign. Prompt cho AI: 'dùng ảnh từ /assets/images/hero.jpg cho phần hero section'."

Bất đồng bộ
Code
Cách xử lý tác vụ mất thời gian mà không làm đơ cả trang. Giống như đặt cà phê mang đi — bạn không đứng chờ, bạn làm việc khác, cà phê xong thì nhận. Web dùng async khi gọi API.

Backend
Phần sau / Server
Hạ tầngCode
Phần người dùng không thấy — nơi data được lưu, xử lý, và bảo mật. Nếu frontend là mặt tiền cửa hàng, backend là kho hàng và văn phòng phía sau.
Ví dụ thực tế
✳ "Form đăng ký của tôi lưu data ở đâu?" → Supabase là backend. Nó nhận data từ form (frontend) và lưu vào database.

Ví dụ thực tế

Boolean
True / False
Code
Kiểu dữ liệu chỉ có 2 giá trị: đúng hoặc sai (true/false). Dùng để kiểm soát logic — ví dụ: "isLoggedIn: true" nghĩa là người dùng đã đăng nhập.
Ví dụ thực tế
✳ Prompt: "Thêm tính năng toggle — khi bật thì hiện banner, khi tắt thì ẩn." AI sẽ dùng boolean showBanner: true/false.

CodeDesign
Một khối giao diện độc lập, có thể dùng lại nhiều lần. Button, card sản phẩm, navbar, form — đều là component. Thiết kế một lần, dùng ở khắp nơi trong web.
Ví dụ thực tế
✳ "Tôi có 12 trang web nhưng muốn cùng 1 footer. Đây là lúc dùng Footer component — sửa một chỗ, cập nhật khắp nơi."

Command Line Interface
Hạ tầng
Giao diện dòng lệnh — bạn gõ lệnh chữ thay vì click. Terminal trong VS Code là CLI. Claude Code chạy trên CLI. Đây là cách dev (và vibecoder) nói chuyện với máy tính.
Ví dụ thực tế
✳ Gõ "npm run dev" vào terminal = CLI đang chạy lệnh khởi động server. Không cần hiểu sâu, chỉ cần biết copy-paste đúng lệnh.

CSS
Cascading Style Sheets
DesignCode
Ngôn ngữ kiểm soát giao diện — màu sắc, kích thước, khoảng cách, font, layout. Nếu HTML là khung xương thì CSS là da thịt và quần áo. Bạn không cần viết CSS — Tailwind làm giúp.
Ví dụ thực tế
✳ Prompt: "Đổi màu nền hero section sang màu kem #f5f0e8, chữ heading to hơn, thêm padding trên dưới." — AI sẽ chỉnh CSS cho bạn.

Cache
Bộ nhớ đệm
Hạ tầng
Lưu tạm kết quả để lần sau truy cập nhanh hơn. Giống như nhớ đường đi — lần đầu phải tra bản đồ, lần sau thuộc rồi đi liền. Cache giúp web load nhanh hơn.
Ví dụ thực tế
✳ "Tôi sửa web rồi nhưng người dùng vẫn thấy phiên bản cũ" → Đây là vấn đề cache. Xóa cache hoặc hard reload (Ctrl+Shift+R) để thấy bản mới.
Commit

WorkflowCode

Ví dụ thực tế
✳ Sau khi hero section chạy ổn: "git commit -m 'hero section done'". Giờ dù AI có làm hỏng phần sau, bạn vẫn rollback về được.

Database
Cơ sở dữ liệu
Data
Nơi lưu trữ dữ liệu có cấu trúc. Giống như một file Excel khổng lồ nhưng nhanh hơn, an toàn hơn, và có thể truy vấn phức tạp. Supabase, PostgreSQL là ví dụ phổ biến.
Ví dụ thực tế
✳ "Mỗi khi khách submit form, thông tin được lưu vào Supabase database" — một bảng, mỗi hàng là một submission.
Dependency
Thư viện phụ thuộc
Code
Code của người khác mà project bạn dùng. Giống như nguyên liệu đầu vào — bạn không tự làm bơ, bạn mua từ ngoài. npm install là lệnh cài dependency.
Ví dụ thực tế
✳ "module not found" error = project đang cần một dependency chưa được cài. Paste lỗi cho AI, nó sẽ chạy lệnh cài giúp.
DOM
Document Object Model
CodeDesign
Cách trình duyệt "nhìn" trang web — một cây cấu trúc của tất cả elements. JavaScript tương tác với DOM để thay đổi trang mà không cần reload.
Ví dụ thực tế
✳ Khi bạn click nút và counter tăng lên mà trang không reload — JavaScript đang update DOM trực tiếp.
Dynamic
Nội dung động
Code
Nội dung thay đổi theo người dùng, thời gian, hoặc dữ liệu — không cố định như ảnh và chữ. Trang profile của mỗi user khác nhau = dynamic. Trang giới thiệu công ty = static.
Ví dụ thực tế
✳ "Hiển thị số lượt view theo thời gian thực" = dynamic content. Mỗi lần load là fetch data mới từ database.

Environment

Hạ tầng
Ngữ cảnh code đang chạy — máy của bạn (local/dev), server test (staging), hoặc bản thật (production). Mỗi environment có config và database riêng để không làm vỡ bản thật.

.env
Environment Variables
Hạ tầng
File chứa các biến bí mật — API key, password database, token. Không bao giờ upload file này lên GitHub. Vercel cho phép bạn set env variables trong dashboard thay vì file.

✳ "NEXT_PUBLIC_SUPABASE_KEY=xxx" trong file .env — đây là API key để connect với Supabase. AI sẽ hỏi bạn điền vào đây khi setup project.

I3 thuật ngữ
Inference
AI xử lý và trả kết quả
AI
Quá trình AI nhận input (prompt của bạn) và tạo ra output (text, code, ảnh). Mỗi lần bạn hỏi AI và AI trả lời = một lần inference chạy trên server.
Ví dụ thực tế
✳ "Inference cost" = chi phí mỗi lần gọi AI API. Khi bạn dùng Claude API trong app, mỗi user message = một lần inference = một khoản phí nhỏ.
Interface (UI)
Giao diện người dùng
Design
Tất cả những gì người dùng nhìn và chạm vào — không phải logic phía sau. UI tốt là UI mà người dùng không cần đọc hướng dẫn cũng dùng được.
Ví dụ thực tế
✳ "Tôi muốn redesign UI của tool nội bộ" → Prompt: mô tả layout mới bạn muốn, AI sẽ viết component React với giao diện đó.
Import / Export
Chia sẻ code giữa file
Code
Cách một file dùng code từ file khác. Import = lấy vào. Export = chia sẻ ra. Khi AI tạo component, nó thường có "export default" ở cuối để các trang khác import vào được.
Ví dụ thực tế
✳ "import Button from './Button'" = trang này đang dùng component Button từ file Button.tsx. Nếu thiếu dòng này, component sẽ không hoạt động.

DataCode

Ví dụ thực tế

Code

Ví dụ thực tế
✳ Khi Cursor tạo component, nó tạo file .tsx với JSX. Bạn không cần hiểu cú pháp — chỉ cần biết đây là "HTML nâng cấp" mà AI viết cho bạn.
L4 thuật ngữ

Hạ tầng
Môi trường chạy web ngay trên máy bạn — chỉ bạn thấy, internet không thấy. Địa chỉ thường là localhost:3000. Đây là nơi bạn test trước khi deploy.
Ví dụ thực tế
✳ "npm run dev" → mở localhost:3000 trên browser → bạn thấy web của mình. Mỗi lần save file, web tự reload (hot reload).

Loop
Lặp lại tự động
Code
Tự động lặp lại một đoạn code với từng item trong danh sách. Khi bạn có 50 sản phẩm và muốn hiển thị card cho từng cái — loop xử lý việc đó mà không cần viết 50 lần.
Ví dụ thực tế
✳ "Hiển thị tất cả bài blog từ Supabase" → AI viết loop map qua array posts, render BlogCard cho từng bài. Thêm 100 bài vẫn chạy, không cần sửa code.
LLM
Large Language Model
AI
Mô hình AI được train trên lượng text khổng lồ để hiểu và tạo ngôn ngữ. Claude, GPT-4, Gemini đều là LLM. Đây là "não" của các AI tool bạn đang dùng.
Ví dụ thực tế
✳ "Cursor dùng LLM nào?" → Cursor cho phép chọn model: Claude Sonnet, GPT-4o. Model = LLM cụ thể bạn đang chat với.
Xem thêm:ModelPrompt
Letter Spacing
Giãn cách ký tự / Tracking
Design
Letter Spacing (hay Tracking) là khoảng cách giữa các ký tự trong một đoạn văn bản. Chỉnh letter spacing giúp chữ dễ đọc hơn hoặc tạo ra phong cách typography riêng biệt.
Ví dụ thực tế

Margin
Khoảng cách ngoài element
Design
Margin là khoảng cách từ phần tử (element) ra bên ngoài, dùng để ngăn cách nó với các "hàng xóm" xung quanh. Trong khi Padding là khoảng thở bên trong, thì Margin là khoảng trống bên ngoài. Nếu không có margin, các khối nội dung sẽ dính sát vào nhau, gây cảm giác chật chội và khó đọc.
Ví dụ thực tế
✳ "Các section trên landing page đang bị dính vào nhau." → Giải pháp: Thêm margin-bottom cho từng section. Trong Tailwind, bạn dùng class như mb-12 (margin bottom 3rem) hoặc my-8 (margin dọc 2rem).

Model
Phiên bản AI
AI
Phiên bản cụ thể của một AI — như "Claude Sonnet 3.7" hay "GPT-4o". Mỗi model khác nhau về tốc độ, chi phí, và khả năng. Model mạnh hơn = đắt hơn, chậm hơn nhưng code tốt hơn.
Ví dụ thực tế
✳ Trong Cursor: chọn model ở góc phải. Claude Sonnet 3.7 = tốt cho code phức tạp. Claude Haiku = nhanh hơn, rẻ hơn cho task đơn giản.
MCP
Model Context Protocol
AIWorkflow
Giao thức giúp AI kết nối trực tiếp với tool bên ngoài — Supabase, Vercel, Notion, GitHub. Thay vì copy-paste data cho AI, MCP cho phép AI tự đọc và thực hiện action trên các tool đó.
Ví dụ thực tế
✳ "Cursor với Supabase MCP" → AI có thể đọc schema database của bạn và tự viết query đúng cấu trúc, không cần bạn giải thích từng bảng.

npm
Node Package Manager
Hạ tầng
Công cụ cài và quản lý thư viện code. Giống App Store nhưng cho code — gõ "npm install tên-thư-viện" là cài xong. Đi kèm với Node.js.
Ví dụ thực tế
✳ "npm install" trong terminal = cài tất cả dependency của project. "npm run dev" = chạy server local. 2 lệnh này dùng hàng ngày khi vibecode.

Môi trường chạy JavaScript
Hạ tầng
Phần mềm cho phép chạy JavaScript ngoài trình duyệt — trên server, terminal. Next.js cần Node.js để chạy. Bạn chỉ cần cài một lần, không cần hiểu sâu.
Ví dụ thực tế
✳ Lần đầu setup project: tải và cài Node.js từ nodejs.org → sau đó mọi lệnh npm đều dùng được. Cài một lần dùng mãi.
P4 thuật ngữ
Padding
Khoảng cách bên trong
Design
Khoảng trống bên trong một element, giữa content và đường viền. Button có text quá sát mép = thiếu padding. Tailwind: "p-4" = padding 1rem tất cả phía.
Ví dụ thực tế
✳ "Text trong card bị chật quá" → Tăng padding: "p-6" hoặc "px-4 py-3" (padding ngang 1rem, dọc 0.75rem).
Props
Properties / Thuộc tính
Code
Dữ liệu truyền vào component từ bên ngoài. Giống như thông số khi gọi món — cùng món Phở nhưng "không hành, thêm tái" là props khác nhau.
Ví dụ thực tế
✳ <Button text="Đăng ký" color="accent" /> — "text" và "color" là props. Component Button nhận props này để render đúng theo yêu cầu.
Prompt
Câu lệnh cho AI
AI
Đoạn text bạn gửi cho AI để hướng dẫn nó làm việc. Prompt tốt = kết quả tốt. Prompt mơ hồ = AI đoán mò. Đây là kỹ năng quan trọng nhất trong vibecode.
Ví dụ thực tế
✳ Prompt tệ: "Làm trang web đẹp". Prompt tốt: "Tạo landing page Next.js có hero section, countdown 3 ngày, form email, màu brand #E8410A, responsive mobile."
Port
Cổng kết nối
Hạ tầng
Số định danh cho service đang chạy trên máy. localhost:3000 → port 3000 là Next.js. Port 5432 là PostgreSQL. "Port already in use" = có app khác đang chiếm port đó.
Ví dụ thực tế
✳ "Error: port 3000 is already in use" → Một cửa sổ terminal khác đang chạy dev server. Tắt đi hoặc dùng port khác: "npm run dev -- --port 3001".
R3 thuật ngữ
Responsive
Giao diện thích nghi
Design
Web tự điều chỉnh giao diện theo kích thước màn hình — desktop, tablet, mobile. Tailwind có prefix "md:", "lg:", "sm:" để viết style riêng cho từng breakpoint.
Ví dụ thực tế
✳ "grid-cols-3 md:grid-cols-1" = desktop 3 cột, mobile 1 cột. Luôn nhờ AI làm responsive — đây là best practice không thể bỏ qua.
Request / Response
Yêu cầu / Phản hồi
Hạ tầng
Cách client và server nói chuyện. Client gửi Request (yêu cầu), server trả Response (kết quả). Mỗi khi web load data từ API là một cặp Request-Response.
Ví dụ thực tế
✳ "400 Bad Request" = server không hiểu yêu cầu. "404 Not Found" = không tìm thấy. "500 Server Error" = server bị lỗi. Paste error code này cho AI để fix.
Repository
Kho code
Workflow
Thư mục project được Git quản lý, chứa toàn bộ code và lịch sử thay đổi. Mỗi project = một repository (repo). Lưu trên GitHub để có backup và deploy được lên Vercel.
Ví dụ thực tế
✳ "Tạo repo mới trên GitHub, clone về máy, code, commit, push." — đây là quy trình cơ bản. Claude Code có thể làm hầu hết bước này cho bạn.
S3 thuật ngữ
State
Trạng thái của component
Code
Dữ liệu tạm thời bên trong component — thay đổi thì UI tự cập nhật. Số lượng sản phẩm trong giỏ hàng, tab đang active, hay filter đang chọn — đều là state.
Ví dụ thực tế
✳ "Khi nhấn nút Thêm vào giỏ, số lượng tăng lên ngay mà không reload trang" → State đang quản lý số lượng đó và trigger re-render UI.
Supabase
Backend as a Service
DataHạ tầng
Nền tảng backend miễn phí — database, authentication, storage, realtime, tất cả trong một. Marketer dùng vibecode hầu hết chọn Supabase vì không cần setup server.
Ví dụ thực tế
✳ "Lưu form submissions, quản lý user đăng nhập, upload ảnh campaign" — Supabase xử lý hết 3 việc này. Tích hợp với Next.js trong vài dòng code.
Spacing
Hệ thống khoảng cách
Design
Spacing (khoảng cách/giãn cách) là thuật ngữ chỉ khoảng không gian giữa các yếu tố như chữ, dòng, đoạn văn trong soạn thảo (Word) hoặc các phần tử thiết kế đồ họa/website. Mục đích là tăng khả năng đọc hiểu và tạo bố cục cân đối. Nó bao gồm giãn dòng (line), khoảng cách đoạn (paragraph) và khoảng cách ký tự.
Ví dụ thực tế
✳ "Trang trông lộn xộn" thường do spacing không nhất quán. Prompt: "Thống nhất spacing giữa các section thành 64px, giữa card nội dung thành 16px."

Code

Ví dụ thực tế
✳ "Type error" trong terminal = TypeScript phát hiện bạn đang dùng sai kiểu dữ liệu. Paste lỗi cho AI, nó tự fix kiểu dữ liệu cho đúng.

DesignCode

Ví dụ thực tế

✳ Cheat sheet · dùng ngay không cần nhớ

Khi AI hoặc dev nói những từ này, đây là ý họ muốn nói.

"Push lên main"
Upload code mới nhất lên GitHub nhánh chính → Vercel tự deploy.
"Cần refactor"
Viết lại code cho gọn hơn, không thêm tính năng. Không cần lo — AI làm được.
"Build failed"
Code có lỗi, không deploy được. Paste log lỗi cho AI để fix.
"Cần API key"
Mã bí mật để dùng service bên ngoài. Lấy từ dashboard của service, paste vào .env.
"Schema database"
Cấu trúc bảng trong database — có những cột gì, kiểu dữ liệu gì.
"Hydration error"
Server render khác client render. Paste lỗi cho AI, thường fix được nhanh.
"500 error"
Server bị lỗi. Xem log trên Vercel dashboard hoặc terminal để tìm nguyên nhân.
"CORS error"
API không cho phép domain của bạn gọi. Cần config whitelist domain hoặc dùng proxy.
